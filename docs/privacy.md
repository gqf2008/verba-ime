# 隐私说明（远程 LLM 数据出境）

> 更新：2026-09-24 · 适用 AI 链路（含多轮上下文、上屏上下文与悬浮 AI 回复按钮）。

## 原则
- **本地优先**：输入法组合/直输全部本地完成，不上传。
- **远程显式授权**：LLM 为远程能力，用户必须显式配置服务商（base_url / key / model）后才能使用。
- **默认关闭**：未配置服务商时 AI 模式提示配置，不静默外发。

## 使用 `//` AI 模式时会发生什么
1. 你输入的**提示词**（`//` 之后的内容）会发送至配置的 LLM 服务商。
2. 服务商的返回流式回传并在 preedit 显示。
3. **多轮上下文**（`ai_context_turns` > 0，新装默认 50 轮；已落盘配置保持原值）：daemon 在**内存中**按窗口保留最近对话轮次，下次 `//` 请求时随提示词一并发送给 LLM；`//new` 清空当前窗口会话。daemon 重启即清空，不落盘。
4. **上屏上下文**（2026-09-22 起，默认开启，同 `ai_context_turns` 控制）：用户**上屏的文字**（拼音候选、标点、英文、OCR 结果等）会并入当前窗口的 AI 上下文会话，下次 `//` 请求时以 `[上屏] ` 标注随历史发送给 LLM。AI 生成结果的回写不重复外发（已在对话历史中）。
   - **请注意**：这意味着你在输入框中打出的内容（含聊天、文档内容）会被发送到你配置的 LLM 服务商。若不想外发，把 `ai_context_turns` 设为 0（关闭多轮与上屏上下文）。
   - 上屏内容只按「窗口」隔离（同窗口内可见），跨窗口/跨应用不混。
5. **缓解措施**（2026-09-22）：
   - **窗口关闭 = 会话销毁**：前端检测到窗口已关闭后通知 daemon 删除该窗口的会话历史与代际（macOS 查 CGWindowList、Windows 查 IsWindow）；焦点切换（旧窗口仍开着，含最小化/切到其它 Space）不丢上下文。已知边界：关闭未被检测到的极端情形下（关闭后从未发生焦点切换、窗口身份被系统复用且未触发检测），旧上下文可能残留或被新窗口继承，由 LRU/重启兑底。
   - **敏感字段检测（尽力而为）**：Windows 按 TSF 输入范围判密码字段（IS_PASSWORD）；macOS 探测原生 `secureTextEntry`。检测到的密码类字段不上屏外发；未标准声明安全输入的字段（部分网页/App 自绘密码框）可能检测不到。
   - **`//new`**：会话清空命令（旧 in-flight 请求回写被代际拦截）。
6. **数据出境提示**：若服务商在境外（如 OpenAI），提示词将离开本机/出境。建议：
   - 避免输入敏感信息到 AI 模式；
   - 使用境内服务商（DeepSeek / Qwen / Kimi / GLM 等）或自建（Ollama / vLLM）以控制数据流向。

## 悬浮 AI 回复按钮（`float_button_enable`，默认关闭，2026-09-24 起）

开启后（配置文件 `float_button_enable = true`，v1 设置面板不暴露、只读配置）：

1. 输入法激活时在光标旁显示悬浮按钮（密码类安全输入字段不弹）。
2. 点击后截取**当前前台窗口在屏幕上的可见区域**（走系统屏幕录制权限，截图在本机完成）。
3. 截图经**本地 OCR**（默认 rapid 本地模型）转成文字——**截图图片本身不外发**。
4. OCR 文字按 `float_button_prompt` 模板（必含 `{ocr}` 占位，可自定义）拼接后，随生成请求发送给你配置的 LLM 服务商——**屏幕上的文字内容会出网**，出网边界与 `//` AI 模式相同。
5. 该次问答进入当前窗口的 AI 上下文会话（与 `//` 同会话、同销毁语义），生成回复可继续追问。

边界与缓解：
- 默认关闭；不用即不产生任何截图与出网。
- 「截窗口」截的是屏幕可见区域：被其它窗口遮挡的部分会带遮挡内容，不追求离屏窗口像素。
- 同 `//` 的敏感字段标准：密码类输入字段不弹按钮（macOS `secureTextEntry` / Windows TSF `IS_PASSWORD`，尽力而为，未标准声明的自绘密码框可能探不到——与 `//` 链路同一探测口径与同一残留风险）。
- 想换提示词口径就改 `float_button_prompt`；想彻底关闭就把 `float_button_enable` 置回 `false`。

## 不收集
- 输入法不采集、不上报任何本地输入内容（上屏上下文仅在你启用了多轮上下文时，随你的 `//` AI 请求发送给你自己配置的服务商，见上）。
- 日志默认不记录用户文本与密钥；调试日志仅本地存储。
- 麦克风/截图（M3 上线）将走系统权限并在首次使用前提示。

## 服务商密钥
- API Key 存于系统凭据库（Windows DPAPI / macOS Keychain / Linux Secret Service），不写入配置文件。
- 开发环境可用 `VERBA_API_KEY` 环境变量兜底（仅限开发）。

## 开关
- 不配置服务商 = 完全关闭远程能力；配置后每次使用仍可在设置面板（M4）关闭。
