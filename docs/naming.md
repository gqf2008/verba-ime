# 命名与品牌

> 更新：2026-08-22 · 状态：已选定主名，候选备选。

## 选定名称

- **英文名：Verba** —— 拉丁语，意为「言语 / 文字」（verbum 的复数）。
- **中文名：拾言** —— 「拾」取 OCR（拾取图像文字）与 ASR（拾音）之意，「言」即文字与语言。
- **口号**：**「声、像、思、音，皆成文字」**；英文 **"Every word, every way."**

### 命名理由
1. 语义贴合产品：输入法的本质是把「任何表达方式变成文字」——Verba 直指「文字」，拾言点明「收集语言」。
2. 跨语言易读易记：5 个字母、国际可读，中文名两个常用汉字，检索不易与知名产品冲突（已检索无同名输入法）。
3. 可扩展：未来做翻译 / 词典 / 编辑器方向时品牌仍成立。

## 视觉方向（草案）

- **图标概念**：一个「言」字 / 对话气泡 + 声波纹 + 取景框（取景框 = OCR，声波 = ASR/TTS，气泡 = LLM），三元素合一，呼应多模态。
- **配色**：深空蓝（科技 / 可靠）+ 灵光青（AI / 语音）+ 暖橙点缀（活力）。
- **字体**：中文思源黑体 / 英文 Inter，开源可商用。
- **仓库 / 品牌资源**：`assets/branding/`（图标源文件、配色、横幅），随 M0 收尾补充。

## 品牌使用约定

- 项目 / 仓库名使用英文 `verba-ime`；产品展示使用「Verba · 拾言」。
- 文档中首次出现写全称，之后可用简称 Verba。
